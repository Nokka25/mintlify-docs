<Update label="2026-04-20" description="Week of April 20" tags={["Feature", "Update"]}>
  ## New features

  - **AI tools integration** — You can now use [Cursor](/ai-tools/cursor), [Claude Code](/ai-tools/claude-code), and [Windsurf](/ai-tools/windsurf) to write and maintain your documentation. Install the Mintlify skill to give your AI editor access to component references, writing standards, and workflow guidance.
  - **Contextual sharing options** — Readers can now open any page directly in ChatGPT, Claude, Perplexity, Cursor, or VS Code. A new MCP option is also available for tool-based workflows.

  ## Updates

  - **API playground improvements** — The API playground now supports `show`, `simple`, and `hide` display modes, giving you more control over how interactive your API reference pages are. Learn more in [API settings](/essentials/settings).
  - **Reusable snippets** — You can create [reusable snippets](/essentials/reusable-snippets) using default exports, shared variables, or component functions to keep your documentation DRY.
</Update>

<Update label="2026-03-23" description="Week of March 23" tags={["Feature", "Update"]}>
  ## New features

  - **Drilldown interaction** — You can now click into nested content to explore topics in more depth. This provides a smoother, more interactive navigation experience throughout the docs.
  - **Automatic 404 redirects** — Broken or outdated links now automatically redirect to the closest matching page, so you never hit a dead end.

  ## Updates

  - **Last updated timestamps** — Each page now shows when it was last modified, making it easier to tell how current the content is.
</Update>
